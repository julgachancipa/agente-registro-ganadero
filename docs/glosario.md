# Glosario ganadero (Colombia)

Vocabulario que el agente debe entender. Se incluye en el prompt del sistema. Ampliar con lo que aparezca en mensajes reales: cambia por región.

| Término | Significado | Mapeo |
|---|---|---|
| Parida | Vaca que parió recientemente / en lactancia | estado productivo: lactando |
| Horra / vacía | Hembra no preñada | estado reproductivo: vacía |
| Escotera | Vaca seca y no preñada | seca + vacía |
| Cargada / preñada / llena | Hembra gestante | estado reproductivo: preñada |
| Novilla de vientre | Hembra joven apta para reproducción | categoría: novilla |
| Mamona | Cría lactante | categoría: ternera/o |
| Levante | Etapa entre destete y ceba o primer servicio | categoría |
| Ceba | Engorde para sacrificio | propósito |
| Secar | Dejar de ordeñar antes del parto | evento: secado |
| Echarle el toro / cubrir | Monta natural | evento: servicio (monta) |
| Inseminar / pajilla | Inseminación artificial / dosis de semen | evento: servicio (IA) |
| Palpar | Diagnóstico de preñez | evento: palpación |
| Chapeta / arete | Identificación en la oreja | número del animal |
| Potrero / lote | Área de pastoreo | potrero |
| Rotar / pasar | Mover animales de potrero | evento: traslado |
| Purgar | Desparasitar | evento: tratamiento |
| Botó la cría / abortó | Aborto | evento: parto (resultado: aborto) |
| Se murió / se cayó | Muerte | evento: muerte |
